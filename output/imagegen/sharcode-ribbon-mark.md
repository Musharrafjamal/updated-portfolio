# Sharcode ribbon symbol

A native editable SVG identity, drawn directly in paths. The mark combines broad asymmetric S turns with matching diagonal terminal cuts. A narrow ivory seam and a lime return fold suggest a continuous ribbon turning through code. It is a free-standing symbol paired with the lowercase `sharcode` wordmark; it contains no SC lettering or app-square container.

The header component preserves its existing API, classes, 30px footprint, accessible wrapper behavior and responsive wordmark variables. `public/sharcode-symbol.svg` stores the reusable symbol. `public/favicon.svg` adds an ivory contrast plate specifically for browser tabs, and the 16px/32px PNG favicons and 180px Apple touch icon are Sharp exports of those exact native paths.

Small-size inspection: compare the header mark at 30px, favicons at 16px and 32px, and the symbol at 48px. The S silhouette remains primary at small sizes, while the seam and lime fold provide detail at larger sizes.

No raster image-generation prompt was used for this native vector logo. `output/imagegen/sharcode-ribbon-mark-reference.png` is a 512px transparent export of the exact final native symbol for social-banner regeneration.
